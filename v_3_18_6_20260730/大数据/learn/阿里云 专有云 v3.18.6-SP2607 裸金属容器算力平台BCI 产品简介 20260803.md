# 1.产品详情

裸金属容器算力平台BCI（Bareless Containers Instance），融合了BareMetal（裸金属）与Serverless（无服务器），提供Serverless化的容器服务。您无需管理底层服务器，也无需关心运行过程中的容量规划，只需要提供打包好的Docker镜像，即可运行容器。

BCI融合了GPU 裸金属服务器、专有网络VPC、高性能网络CPN、高性能存储与Serverless 容器化能力，面向 AI 大模型与AI Agent 提供秒级的实例编排及供给。您仅需要提供大模型框架及Agent Runtime的镜像地址，按需开通runD容器镜像组实例规格，即可实现AI 智能体的秒级快速部署。

- BCI工作在智算IaaS层，为AI PaaS、AI MaaS提供稳定、弹性的智算算力服务。

- BCI在裸金属实例方面，可以实现南北向网络融入原有云网络，实现更大的云内产品网络带宽，系统盘、数据盘使用EBS存储，支持网络ACL、EIP，块存储冗余、快照、镜像、回收站等高级企业特性，实现算力服务与云的更进一步融合。通过DPU的方式，可快速实现GPU服务器在裸金属与Serverless容器的快速切换。

- BCI在容器服务方面根据不同的GPU特性提供runD/runC的容器实例，支持**GPU直通、GPU-CPN等GPU资源实例**，提供丰富的GPU资源粒度实例，结合runD安全容器的承载，实现物理GPU服务器跨租户的资源分配与供给，提升云平台对GPU的细粒度池化能力。

- 在容器编排、调度服务方面支持对接ACS、ACK、开源Kubernetes等实现Kubernetes的编排、负载均衡、调度等能力，同时支持直接基于BCI控制台、OpenAPI来使用**容器化算力，提供多样性的算力使用方式。**

<a id="section-2"></a>

# 2.产品价值

**Serverless**

采用Serverless架构，基础设施托管。您无需关心底层服务器，只需要提交容器镜像；无需预先创建集群和维护集群，无需关注运行过程中的容量规划，可以专注业务领域创新。

**GPU 资源池化**

- <strong>多样化 GPU 实例类型：</strong>基于runD 安全容器技术，提供GPU直通实例、GPU-CPN实例、GPU超节点实例，满足从训练到推理的全场景需求。

- **跨租户资源池化**：

  - 通过 runD 容器隔离机制，实现多租户间GPU资源的安全、高效分配，显著提升 GPU 利用率与平台调度灵活性。

  - CPU通算实例与GPU通算实例共池，极致压缩算力资源密度，大幅提升用户裸金属算力资源利用率。

**高弹性**

BCI融合了GPU 裸金属服务器、专有网络VPC、高性能网络CPN、高性能存储与Serverless 容器化能力，面向 AI 大模型与AI Agent 提供秒级的实例编排及供给。您仅需要提供大模型框架及Agent Runtime的镜像地址，按需开通runD容器镜像组实例规格，即可实现AI 智能体的秒级快速部署。

**兼容主流Kubernetes 生态**

基于Virtual Kubelet，通过虚拟节点方式原生支持对接容器镜像服务ACK、容器计算服务ACS及开源Kubernetes，提供完整的容器编排、服务发现、负载均衡与自动扩缩容能力。

**易用性**

简单易用的统一管理、控制界面，可以直接创建和管理容器化算力实例，无需复杂集群运维，满足快速部署、临时任务等轻量场景。

<a id="section-3"></a>

# 3.应用场景

BCI 为 AI 工作负载提供了极具弹性的解决方案，全面覆盖从模型训练到推理部署的完整生命周期。它将Serverless 弹性调度、自动扩缩容的特性与强大的 GPU 计算能力相结合，帮助开发者和数据科学家专注于业务逻辑与算法创新，而非底层资源管理。

**模型训练**

在模型训练这一计算密集型环节，BCI 允许您根据模型大小和收敛速度的需求，灵活选择所需规格的 GPU实例，无需等待冗长的装机流程。对于大规模分布式训练，BCI 高网实例搭配 CPN RDMA 高速互联，提供极致的卡间通信性能。训练中断后可从 checkpoint 快速恢复，显著提升训练效率。

**推理部署**

模型训练完成后，可以将其无缝部署为在线推理服务。BCI 的 Serverless 架构能够根据实时请求流量自动扩缩容 GPU 实例，快速拉起新实例响应突发流量。这种弹性能力非常适合流量波动大的 AI 应用场景，如大模型推理、图像识别、自然语言处理等，确保服务始终保持高可用。

**容器组管理**

弹性容器组是敏捷安全的Serverless容器运行服务。一个容器组由GPU、vCPU、内存、网络等基础组件组成的sandbox实例，用于运行一个或多个容器。
