# 1.什么是裸机管理

裸机管理BMS（Bare Metal Service）是指将物理服务器通过云平台来按需和弹性的提供给租户使用的一种云服务，通常用来为核心数据库、关键应用系统、高性能计算等业务提供计算资源支撑。

裸机管理服务借助专有云一体化运维平台，实现了对物理机进行深度且精细的节点级管理。这一功能包括但不限于添加、删除物理机节点，电源状态控制，以及系统部署等核心操作。在圆满完成了服务器的基础搭建与配套预配置任务后，管理员能够通过直观易用的UI界面实现裸金属设备的批量部署。部署阶段结束后，可利用这些裸金属设备构建高性能的裸金属主机，并支持用户根据实际需求自定义安装各种操作系统，涵盖x86架构下的AliOS和CentOS，以及SW环境下的deepOS和AliOS。此外，该服务还提供了对裸金属主机从创建到退役的全生命周期精细化管理。

**特点和优势**

**全生命周期运维管理**

覆盖裸机资源从注册、释放、删除到重新注册的完整生命周期管理，支持远程开关机、强制重启、属性配置、主机名修改、密码重置及带外控制台登录等精细化运维操作。通过集中化操作减少人工干预，降低运维复杂度。

**多维度监控与告警**

实时监控CPU、内存、磁盘、网络等关键性能指标，辅助容量规划。裸机实例和托管实例提供统一告警展示、分级处置及闭环管理。通过多维数据关联分析，能够快速定位问题根源，从而提升系统稳定性。

**标准化与灵活配置**

支持对镜像、网络、机型及GPU资源进行标准化管理，通过基础配置管理提升跨团队协作效率，满足动态业务扩展需求，并最大化计算资源的利用率。

**功能特性**

**实例管理**

实例管理为管理员提供覆盖物理机全生命周期的资产运维管理能力，包括实例注册、实例释放、实例删除及重新注册等核心操作，支持对实例执行远程开关机、强制重启等远程运维操作，实现实例状态的实时管控。此外，平台提供实例属性配置、主机名修改、密码重置及带外控制台登录等精细化运维功能，构建完整的裸机实例运维解决方案。

**监控告警**

监控告警为管理员提供裸机资源的监控解决方案，支持对已注册物理机进行统一监控告警管理。监控告警包含如下核心模块：

- 实例监控 提供CPU、内存、磁盘、网络等关键资源的多维性能指标监控，实时呈现资源利用率，助力精准容量规划。

- 裸机实例告警 针对裸机资源，实现故障告警的集中展示与分级处置，支持历史告警追溯与闭环管理。

- 托管实例告警 面向用户侧托管实例，实现故障告警的集中展示与分级处置，支持历史告警追溯与闭环管理。

系统通过监控告警功能实现跨资源类型的故障全景视图，结合告警分级机制，帮助管理员快速定位问题根源并执行高效处置，全面提升裸机资源的可用性与运维响应速度。

**基础配置**

基础配置为裸机实例的注册与运维提供核心参数配置能力，涵盖镜像数据、网络信息、机型信息及GPU异构计算资源配置等维度。基础配置包含如下功能模块：

- **镜像管理** 支持自定义镜像与公共镜像的全生命周期管理，包括镜像导出及状态管理（启用/禁用）。其中，自定义镜像还支持上传和删除。通过镜像管理实现操作系统与应用环境的标准化部署。

- **网络管理** 提供子网信息的查询与获取功能，支持子网参数信息的展示，包括**子网名称**、**IP范围**、**网关**等。

- **机型管理** 支持硬件规格的灵活配置，包括机型创建、参数修改、机型删除，满足多样化的业务场景需求，优化资源利用效率。

- **GPU配置** 实现异构计算单元的精细化管理，支持GPU型号添加、参数编辑及资源释放，保障 AI/ 高性能计算场景的资源适配性。

# 2.快速入门

<a id="section-2-1"></a>

## 2.1. 使用流程

本节介绍裸机管理运维控制台的基本使用流程。通过裸机管理运维控制台，管理员可将裸机注册到专有云平台，并实现裸机的上下电、删除、释放、修改属性、重置密码等运维管理。注意在使用裸机管理运维服务前需要完成基本的服务器上架以及相关网络联通工作。

裸机的基本操作说明如下：

- 添加机型：在进行实例注册时，用户需选择相应的机型。管理员可通过裸机管理运维控制台添加机型，并按照页面提示设置机型名称、CPU 信息、内存信息等相关参数。

- 注册实例：管理员通过裸机管理运维控制台注册裸机服务对裸机进行基本信息配置，选择管理类型、实例架构，指定安装镜像，配置网络信息，输入实例名称和描述信息等完成裸机注册。

- 查询实例详情：支持查询资源池中的所有已注册的裸机实例，每个实例的信息除管理员输入的信息外，还包括系统自动设置的信息，如创建时间、自动分配的IP、裸机运行状态、Agent状态、电源状态、运维状态等。

- 释放实例：支持管理员释放指定ID的裸机，释放后，会进入资源池并重装。裸机释放成功后，用户可再次申请使用。

## 2.2. 登录裸机管理运维控制台

本节为您介绍如何登录到ASO运维控制台，并进入裸机管理运维控制台。

**前提条件**

- 您需要登录ASO运维控制台后进入裸机管理运维控制台，确认您已从部署人员处获取ASO运维控制台的服务域名地址。

- 推荐使用Chrome浏览器。

**操作步骤**

1. 在浏览器地址栏中，输入ASO运维控制台的访问地址，按回车键。

   > **说明**
   >
   > 您可以单击右上角的当前语言切换其它语言。当前支持简体中文、English语言切换。

2. 输入正确的用户名及密码。

   > **说明**
   >
   > - 登录Apsara Uni-manager运维控制台的用户名和密码请从部署人员或管理员处获取。
   >
   > - 若连续输入密码错误三次，系统将启动图片验证码登录功能；若连续输入错误五次，账户将被锁定，请联系管理员进行激活。
   >
   > - 首次登录Apsara Uni-manager运维控制台时，需要修改登录用户名的密码，请按照提示完成密码修改。为提高安全性，密码必须满足以下要求：
   >
   >   - 必须包含英文大小写字母。
   >
   >   - 必须包含阿拉伯数字（0~9）。
   >
   >   - 必须包含特殊符号，包括感叹号（!）、at（@）、井号（#）、美元符号（$）、百分号（%）等。
   >
   >   - 密码长度为10~20个字符。

3. 单击**同意协议并登录**，进入ASO运维控制台页面。

4. 在页面顶部的菜单栏中，选择**产品运维 > 计算运维 > 裸机管理运维控制台-BMS** **。**

## 3.2. 批量注册实例

在裸机管理运维服务中，管理员可以通过上传.xls等格式的文件对裸机实例进行批量注册。本节介绍如何通过上传本地文件批量注册裸机实例。

**前提条件**

已按照模板设置好相关参数的本地.csv/xls/xlsx格式的批量上传文件。模板信息请参见下载模板、模板格式、模板参数说明。

**操作步骤**

1. 登录裸机管理运维控制台。

2. 在左侧导航栏中，单击**实例管理 > 实例列表**。

3. 在**实例列表**页面，单击左上方的**批量注册**按钮。

4. 在弹出的**批量注册**对话框中，根据页面提示选择**地域**和**可用区**。

5. 在上传文件区域，根据模板格式要求填入各参数，并选择文件进行上传。

6. 单击**确定**按钮，完成裸机的批量注册。

**相关操作**

下载模板：在弹出的**批量注册**对话框中，单击**模板**。

## 3.3. 重新注册实例

在裸机运维服务中，管理员可对资源池中的现有裸机实例进行重新注册，从而实现重装机操作。本节介绍如何重新注册实例。

**前提条件**

- 已注册实例，详情请参见注册实例。

- 所需要重新注册的裸机实例资源属主为资源池中。

- 所需要重新注册裸机在线状态需处于稳定状态（如：运行中、已停止、注册失败、无心跳等）。

**操作步骤**

1. 登录裸机管理运维控制台。

2. 在左侧导航栏中，单击**实例管理 > 实例列表**。

3. 在**实例列表**页面，查找待重新注册的实例所在的行，单击该行操作列的**重新注册**。

4. 在弹出的**重新注册**页面中，根据页面提示设置各参数，参数说明请参见注册实例参数说明。

5. 完成上述参数配置后，单击**确定**，完成实例的重新注册。

## 3.5. 释放实例

租户侧的裸机资源需要在租户侧释放，若租户侧释放失败可以在运维控制台执行强制释放，本节介绍如何释放裸机。

**前提条件**

- 已注册裸机，详情请参见注册实例。

- 待释放的裸机资源属主为租户。

- 所要释放的实例操作状态需处于释放失败的状态。

**背景信息**

- 支持管理员对实例列表中资源属主为租户且操作状态为释放失败的裸机执行释放操作。裸机释放后，会进入资源池并重装。裸机释放成功后，ASCM用户可再次申请使用。

- 管理员无权对租户侧实例在线状态为正常的裸机进行释放操作。

> **警告**
>
> 注意：释放实例有一定的风险性，请谨慎操作！

**操作步骤**

1. 登录裸机管理运维控制台。

2. 在左侧导航栏中，单击**实例管理 > 实例列表**。

3. 在**实例列表**页面，查找待释放裸机所在的行，单击该行操作列的**实例状态**。

4. 在弹出的下拉菜单中单击**释放实例**。

5. 单击**释放**完成裸机的释放。

### 5.1.1. 自定义镜像上传

本节介绍如何上传自定义镜像。

**前提条件**

本地具有符合规格的自定义镜像文件。

**背景信息**

用户可以根据实际需求上传自定义的镜像文件，格式限制为.tgz、.qcow2。

**操作步骤**

1. 登录裸机管理运维控制台。

2. 在左侧导航栏中，单击**基础配置 > 镜像管理**。

   默认进入**自定义镜像**页签。

3. 单击**自定义镜像上传**按钮。

4. 在右侧浮动面板中，根据页面提示设置各参数。

   | 配置项 | 是否必填 | 说明 |
   | --- | --- | --- |
   | 地域 | 是 | 镜像所属的地域。 |
   | 可用区 | 是 | 镜像所属的可用区。 |
   | 镜像名称 | 是 | 镜像的名称，镜像上传后会自动填充。 |
   | 系统架构 | 是 | CPU架构，可选的值：<br>• x86_64<br>• aarch64<br>• sw_64 |
   | 平台 | 是 | 镜像的类型。 |
   | 内核版本 | 否 | 内核的版本。 |
   | 模板名称 | 否 | 模板的名称。 |
   | 镜像描述 | 否 | 镜像的描述信息。 |
   | 镜像上传 | 是 | 单击<strong>选择文件</strong>，上传镜像。支持上传的镜像格式为.tgz、.qcow2。<br>说明所登录环境证书会影响到镜像上传，请检查所登录环境证书有效期，如果所登录环境证书已过期，上传镜像时会提示镜像上传失败，如已过期请联系环境管理员或自行解决，自行解决方法如下：<br>i. 单击<strong>选择文件</strong>下方的<strong>单击此处</strong>信任证书。ii. 在弹出的告警页面中，单击<strong>高级</strong>，并选择继续，之后会跳转至新的页面。iii. 完成上述操作后，便可继续上传镜像。 |

5. 单击**确定**按钮，完成镜像上传。

## 5.3. 机型管理

机型管理为管理员提供了对机型的新增、查询、修改和删除功能。通过这些操作，管理员可以灵活地管理机型信息，以满足不断变化的业务需求。机型管理模块有助于确保机型信息的准确性和一致性，从而简化裸机实例的管理和部署。

<a id="section-5-3-1"></a>

### 5.3.1. 添加机型

完成机型创建后，您可以根据实际需求查询并查看已创建机型的相关信息，本节介绍如何添加机型。

**操作步骤**

1. 登录裸机管理运维控制台

2. 在左侧导航栏中，单击**基础配置 > 机型管理**。

3. 在**机型管理**页面中，单击左上角的**添加机型**。

4. 在弹出的**添加机型**对话框中，配置参数。

   | 配置项 | 是否必填 | 说明 |
   | --- | --- | --- |
   | 机型名称 | 是 | 机型的名称。 |
   | CPU架构 | 是 | CPU的架构，可选的值：<br>• x86_64<br>• aarch64<br>• sw_64 |
   | CPU厂商 | 是 | CPU制造厂商，可选值与CPU架构有关。<br>• CPU架构为x86_64时，可选Intel和海光。<br>• CPU架构为aarch64时，可选鲲鹏、飞腾和倚天。<br>• CPU架构为sw_64时，可选SW。 |
   | CPU型号 | 是 | CPU的具体型号规格。 |
   | CPU个数 | 是 | CPU的数量。 |
   | 内存 | 是 | 机型的内存容量大小，单位为G。 |
   | 磁盘大小 | 是 | 机型的磁盘容量大小，单位为G。 |
   | 磁盘类型 | 是 | 存储磁盘的类型。 |
   | GPU厂商 | 否 | GPU的制造厂商，仅在配置GPU时需要填写。关于GPU信息的管理与查阅，请参见GPU配置相关文档。 |
   | GPU型号 | 否 | GPU的型号，仅在配置GPU时需要填写。 |
   | GPU数量 | 否 | GPU的数量，仅在配置GPU时需要填写。 |
   | 网卡个数 | 是 | 网卡的数量。 |
   | 网卡类型 | 是 | 网卡的类型。 |
   | 机器的U数 | 是 | 服务器在机柜中占用的标准机架单位数量。 |
   | 厂商名 | 是 | 服务器的厂商名称。 |
   | 服务器额定功率 | 是 | 服务器在标准工作条件下的额定功耗。 |
   | CPU最小安全频率 | 否 | CPU在安全运行模式下的最低工作频率。 |
   | 描述 | 否 | 机型的描述信息。 |

5. 完成上述参数配置后，单击**确定**，完成机型的添加。

<a id="section-5-3-2"></a>

### 5.3.2. 修改机型

本节介绍如何修改机型的配置信息。

**前提条件**

- 已创建机型，详情请参见添加机型。

- 待修改机型未注册裸机。

**背景信息**

除机型名外，其他的全部属性均可修改。完成机型修改后，管理员可以根据实际需求查询并查看已修改机型的相关信息。

**操作步骤**

1. 登录裸机管理运维控制台

2. 在左侧导航栏中，单击**基础配置 > 机型管理**。

3. 在**机型管理**页面中，查找到需要修改的机型，单击其后面的**修改**。

4. 在弹出的**修改机型**对话框中，根据实际需要重新配置机型的各个参数。参数的详细信息，请参见机型参数说明。

5. 完成上述参数配置后，单击**确定**，完成机型的修改。

<a id="section-5-3-3"></a>

### 5.3.3. 查看机型的详细信息

管理员可以根据实际需求查询并查看已存在机型的相关信息，本节介绍如何查询机型以及查看机型的详细信息。

**前提条件**

已创建机型，详情请参见添加机型。

**操作步骤**

1. 登录裸机管理运维控制台

2. 在左侧导航栏中，单击**基础配置 > 机型管理**。

3. 在**机型管理**页面中，选择筛选条件并在搜索框中输入相应信息，查询出符合条件的机型。当前支持的筛选条件包括：**机型名称**、**磁盘类型**和**厂商**。

4. 在机型列表展示了机型的详细信息，包括**机型名称**、**架构**、**CPU个数**、**CPU厂商**、**CPU型号**等。

<a id="section-5-3-4"></a>

### 5.3.4. 删除机型

本节介绍如何删除机型。

**前提条件**

- 已创建机型，详情请参见添加机型。

- 待删除机型未被裸机实例所引用。

>

4. 在弹出的对话框中，单击**确定**，完成机型的删除。

## 5.4. GPU配置

GPU配置功能包括对GPU信息的新增、查询、修改及删除操作。管理员能够运用此功能添加新的GPU配置信息，高效检索现有GPU配置信息数据，适时更新已存在的配置内容，并在必要时执行删除操作。

<a id="section-5-4-1"></a>

### 5.4.1. 添加GPU

本节介绍如何新增GPU配置信息。

**背景信息**

完成GPU配置信息创建后，您可以根据实际需求查询并查看已创建GPU的相关配置信息。

**操作步骤**

1. 登录裸机管理运维控制台。

2. 在左侧导航栏中，单击**基础配置 > GPU配置**。

3. 在**GPU配置**页面中，单击左上角的**添加GPU**。

4. 在弹出的**添加GPU**对话框中，配置参数。

   | 配置项 | 是否必填 | 说明 |
   | --- | --- | --- |
   | GPU厂商 | 是 | GPU图形处理器的制造厂商。 |
   | GPU厂商（中文） | 否 | GPU图形处理器的制造厂商的中文名称。 |
   | GPU型号 | 是 | GPU图形处理器的具体型号规格。 |
   | GPU型号（中文） | 否 | GPU图形处理器的具体型号规格的中文名称。 |
   | GPU显存大小 | 是 | GPU图形处理器的显存容量大小。 |
   | TFLOPS | 是 | 万亿次浮点运算每秒。 |

5. 完成上述参数配置后，单击**确定**，完成GPU的添加。

<a id="section-5-4-2"></a>

### 5.4.2. 修改GPU信息

本节介绍如何修改GPU的配置信息。

**前提条件**

已创建GPU配置信息，详情请参见添加GPU。

**操作步骤**

1. 登录裸机管理运维控制台。

2. 在左侧导航栏中，单击**基础配置 > GPU配置**。

4. 在弹出的**编辑GPU**对话框中，根据实际需要重新配置GPU的各参数。

   | 配置项 | 说明 |
   | --- | --- |
   | GPU厂商 | GPU图形处理器的制造厂商，不可修改。 |
   | GPU厂商（中文） | GPU图形处理器的制造厂商的中文名称。 |
   | GPU型号 | GPU图形处理器的具体型号规格，不可修改。 |
   | GPU型号（中文） | GPU图形处理器的具体型号规格的中文名称。 |
   | GPU显存大小 | GPU图形处理器的显存容量大小。 |
   | TFLOPS | 万亿次浮点运算每秒。 |

5. 完成上述参数配置后，单击**确定**，完成GPU信息的修改。
