```python
from collections import OrderedDict
import subprocess
import os


def get_java_pid():
    # 执⾏ `ps -ef | grep java` 命令并获取结果
    try:
        result = subprocess.run(["ps", "-ef"], capture_output=True, text=True)
        processes = result.stdout.splitlines()

        # 找到 java 进程的第⼀⾏
        for line in processes:
            if "java" in line and "grep" not in line:
                return line.split()[1], line.split()[7]

    except Exception as e:
        print(f"Error occurred while getting Java PID: {e}")

    return None, None


def dump_thread_stack(pid, jdk_bin, stack_file):
    try:
        command = [
            os.path.join(jdk_bin, "jcmd"),
            pid,
            "Thread.dump_to_file",
            "-format=text",
            "-overwrite",
            stack_file,
        ]

        # 执⾏ jcmd 命令
        subprocess.run(command)
        print(f"Thread stack dumped to {stack_file}")

    except Exception as e:
        print(f"Error occurred while dumping thread stack: {e}")


def main():
    stack_file = "/home/admin/stack.log"
    pid, java_exec = get_java_pid()

    if pid and java_exec:
        jdk_bin = os.path.dirname(java_exec)
        dump_thread_stack(pid, jdk_bin, stack_file)
    else:
        print("No Java process found.")
        return

    stacks = OrderedDict()
    with open(stack_file) as f:
        content = f.read()
        blocks = content.split("\n\n")
        for block in blocks:
            if not block.startswith("#"):
                continue
            split = block.split("\n", 1)
            thread = split[0]
            if len(split) <= 1:
                continue
            stack = split[1]
            if stack not in stacks:
                stacks[stack] = []
            stacks[stack].append(thread)

    stacks = OrderedDict(
        sorted(stacks.items(), key=lambda item: len(item[1]), reverse=True)
    )

    result = ""
    for stack in stacks:
        result += (
            str(len(stacks[stack])) + " in total, " + " , ".join(stacks[stack]) + "\n"
        )
        result += stack + "\n\n"
    result_file = "/home/admin/stack_analyzed.log"
    with open(result_file, "w") as f:
        f.write(result)
    print(f"Thread stack analysis completed. Please check {result_file} for details.")


if __name__ == "__main__":
    main()
```

#### 4.2.1.1. 数据集列表

本文为您介绍在使用数据集列表功能时遇到的告警问题现象、可能原因及解决方案。

1. **数据集列表出现“请联系运维管理员，前往资源管理>全局服务管理中，创建检**

**索与解析服务并分配空间”报错**

问题描述：数据集列表出现“请联系运维管理员，前往资源管理>全局服务管理中，创建检索与解析服务并分配空间”报错。

问题原因：没有为当前空间分配数据集所需的存储资源。

解决方法：以运维管理员身份进入资源管理，将资源分配给当前指定空间。

2. **上传文件并构建了新子集后，数据集列表页显示行数/大小未变化**

问题描述：上传文件并构建了新子集后，数据集列表页显示行数/大小未变化。

问题原因：数据集列表上的数据集统计信息每1小时更新一次；且统计行数及大小均为子集大小，不包含原始文件。

解决方法：更新1小时后重新查看列表页信息。

4. **使用临时凭证操作数据文件时，提示“Access denied by authorizer's**

问题描述：通过数据集OPENAPI获取数据集上传/下载临时凭证后，进行数据文件操作时，提示“Access denied by authorizer's policy”错误。

问题原因：上传凭证仅提供对应数据集目录下的上传动作，下载凭证仅提供对应数据集目录下的下载动作。当操作范围超过限制时提示上述错误，如使用上传凭证进行下载/删除动作、使用上传凭证将文件上传至数据集外的其他路径等

解决方法：

- 若需要进行上传，使用上传凭证完成对应数据集目录下的上传动作

- 若需要进行下载，使用下载凭证完成对应数据集目录下的下载动作

- 若需要进行删除，调用数据集OPENAPI进行数据文件的删除动作

  5. **删除文件出现** **`403 Forbidden`** **错误**

问题描述：在数据集-数据文件中可正常上传并查看文件，但点击删除时提示 `403 Forbidden` 。

#### 4.2.1.3. 数据子集

本文为您介绍在使用数据子集功能时遇到的告警问题现象、可能原因及解决方案。

1. **创建/更新子集提示构建失败，提示“No found any file types match**

**supported type”错误**

问题描述：创建子集提示构建失败，提示“No found any file types match supported type”错误。

问题原因：

- 选中用于创建子集的文件不在可识别的文件类型列表。

- 未正确配置通配符，无法匹配到目标数据文件。

解决方法：

- 若选中用于创建子集的文件不在可识别的文件类型列表，需要将其转换为可识别的文件类型。

- 若以通配符进行文件选择，可在配置完成后，点击创建子集页面的文件预览按钮，若编写正确则会展示前100条匹配的数据文件，基于预览文件确认是否符合预期。

  2. **创建/更新子集提示构建失败，提示“Found multi file modal in your**

**paths”错误**

问题描述：创建/更新子集提示构建失败，提示“Found multi file modal in your paths”错误。

问题原因：数据子集的数据文件配置时，同时选中多种模态的文件。

解决方法：依据错误提示中的信息，仅保留一种模态的数据文件。

3. **进行子集数据预览时，提示视图分页数据过大，无法预览**

问题描述：进行子集数据预览时，提示视图分页数据过大，无法预览。

问题原因：加载子集分页所在的数据块时，超过了单次查询128MB内存限制，其中默认1000行数据划分为1个数据块。

解决方法：拆解大字段为多个小字段或多行数据。

4. **无法进行新建/更新子集操作**

问题描述：打开目标数据集后，新建/更新子集按钮均置灰，无法进行新建/更新子集操作。

问题原因：仅数据集创建者及空间管理员具备子集修改权限

解决方法：授权空间管理员角色

14. **文档深度解析任务结果中常见的边框bbox逻辑说明**

在文档深度解析任务输出结果中，常见解析内容中的边框位置表达格式为数组，样例如下：

**样例：**

[0.1250, 0.2500, 0.1667, 0.2500]

**假设：**

页面尺寸：width=800, height=600

标记边界框：x0=100, y0=150, x1=300, y1=250

**计算：**

x0/width = 100/800 = 0.1250

y0/height = 150/600 = 0.2500

(y1-y0)/height = (250-150)/600 = 100/600 ≈ 0.1667

(x1-x0)/width = (300-100)/800 = 200/800 = 0.2500

**含义：**

该边界框从图像左边 12.5%、顶部 25% 的位置开始，高度占图像 16.67%，宽度占 25%。
