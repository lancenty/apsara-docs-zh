# 1.产品详情

智能体运维平台（OpenTrek Agent Operations Platform，简称 OpenTrek-Ops），是一款基于 xClaw范式的企业级多智能体运维与治理平台，提供以"可托管、可观测、可进化"为本的"云+Agent"一体化运维产品解决方案。面向 AI 智能体提供全生命周期管理，面向业务提供"云+Agent"监管控一体化运维，保障企业 AI 生产力安全可控、规模化落地，让企业智能用云。

<a id="section-2"></a>

# 2.产品价值

智能体运维平台具有开箱即用、安全可控、全栈可观测、成本透明、项目化管理等优势。

**开箱即用**

基于飞天企业版智算底座，支持单体 Agent 与项目一键开通。内置生产环境标准配置，通过标准化模板实现 Agent/xClaw 生产级弹性运行，免去底层环境手动搭建过程，实现分钟级业务部署。原生集成 AI 可观测、AI PaaS、AI IaaS，确保高并发运维场景下的稳定性与资源利用率。

**安全可控**

构建全链路安全审计体系，通过白屏化安全规则配置与敏感操作实时拦截，确保所有运维行为可追溯、可审计，全面满足金融及政务行业的严苛合规要求。系统提供全局安全态势感知能力，直观呈现拦截趋势、风险等级分布及规则命中排行；同时集成文件防护模块，对 Agent 文件操作实施精细化管控。底层架构上，Agent 运行于 ACK 安全沙箱容器之中，利用计算隔离技术进一步夯实运行安全保障，形成从策略配置、实时监控到底层隔离的纵深防御闭环。

**全栈可观测**

覆盖业务指标、应用性能、大模型调用、工具调用、会话消息和安全审计等多维度监控体系。打通业务 → Agent/xClaw → Agent Infra → 云平台 → 基础设施的全景可观测。提供运行日志与对话日志双重记录能力，全链路双日志追溯，同时打通数据洞察能力（Agent 分析、项目 分析、计量智能分析）和 UModel 数据链路，进一步强化多维可观测能力。

**成本透明**

构建全链路透明的 AI 财务资产运营体系，依托精准计量引擎，可视化呈现 Token 消耗与模型用量分布。系统支持按模型、项目、Agent 及用户四大维度进行深度下钻分析，实现从宏观概览到微观明细的多层级成本核算，全面满足项目化运营的精细化管理需求。

**项目化管理**

将 Agent Team 升级为项目管理，面向业务场景统一管理多 Agent 协同项目。提供统计卡片与项目卡片视图，支持项目维度的创建、编排、监控和批量操作，帮助企业以项目为单位高效组织和管理 AI 智能体资源。

**高效运维**

实现 Agent 全生命周期管理，支持 Agent 的一键部署、批量运维（Agent批量启动、停止、下线、重启、扩缩容；批量同步、禁用、删除技能等）。通过 ACK 安全沙箱容器化技术，确保高并发场景下的运行稳定性与资源利用率，大幅降低底层环境搭建与维护成本，助力企业快速构建生产级智能体集群。

<a id="section-3"></a>

# 3.应用场景

智能体运维平台致力于"云+Agent 一体化运维"的用好 AI 场景，即面向 AI 智能体提供全生命周期管理，面向业务提供"云+Agent"监管控一体化运维，让企业管理好云上 Agent、运维好云上 Agent。

**面向 Agent 全生命周期管理**

**核心能力**

构建 Agent"创建态"、"部署态"、"运行态"三态纳管能力，实现面向 Agent 全生命周期应用管理。支持Agent 一键开通、批量运维、弹性伸缩，高代码 Agent（Hermes 类型）接入与源码发布能力，Agent 运行于 ACK 安全沙箱之上。支持项目管理（原 Agent Team 升级），面向业务场景统一管理多 Agent 协同项目。

**应用场景**

- 企业级 AI 智能体规模化部署与管理。

- 多 Agent 协同运维团队（Agent Team）的创建与运营。

- 混合云环境下 Agent 的统一托管与治理。

- 高代码 Agent 的源码开发、部署与运维管理。

- 项目化多 Agent 协同编排与全链路拓扑分析。

- 低码智能体（OpenTrek Dev）的纳管、监控与成本运营场景。

- 多版本形态融合下的统一部署与运维场景。

**客户价值**

以 Agent 为视角和入口，打通 Agent 运维和云平台运维，实现 Agent 全生命周期管理，带给客户低成本、高稳定、高效率的 AI 智能体运维管理体验。

**面向业务"云+Agent"监管控一体化运维**

**核心能力**

从业务视角，构建从业务、Agent/xClaw、Agent Infra、云平台资源到硬件基础设施的"云+Agent"监管控一体化运维，保障业务稳定运行。提供全景可观测、安全审计和成本分析等核心能力。

数据洞察能力（Agent 分析、项目分析、计量智能分析）、UModel 关联数据打通、安全总览仪表盘和文件防护模块，进一步增强监管控一体化能力。

**应用场景**

- 企业级 AI 生产力安全可控的规模化落地场景。

- 金融、政务等强合规要求下的 Agent 运维治理场景。

- 数据驱动的 Agent 效能分析与运营优化场景。

- 基于运行态势图与效果评估的应用效果运营与持续优化场景。

**客户价值**

以 Agent 为视角和入口，打通 Agent 运维和云平台运维，实现"云+Agent"监管控一体化运维，实现故障快速发现、快速定位定界、快速恢复，保障业务稳定运行。

# 5.基本概念

| 概念 | 说明 |
| --- | --- |
| Agent | Agent（智能体）是基于大语言模型的自主执行实体，能够理解自然语言指令、自主规划任务步骤、调用外部工具并完成业务闭环。 |
| Agent Team | V1.1.1起不再演进，建议使用项目化管理。Agent Team 原为由多个 Agent 组成的协同工作编组，用于实现复杂任务的分工协作与成员管理。 |
| MCP（Model Context Protocol） | MCP（模型上下文协议）是 Agent 与外部数据源、工具之间进行标准化交互的开放协议，为 Agent 提供统一的上下文访问接口。 |
| 技能（Skill） | 技能是 Agent 可调用的预定义能力单元，封装了特定的操作逻辑和参数规范，使Agent 能够执行特定领域的任务。 |
| Agent Infra | Agent Infra（Agent 基础设施层）是支撑 Agent 运行、调度和管理的底层平台服务，提供模型接入、工具注册、会话管理等核心能力。 |
| 安全设置 | 安全设置是 Agent 运行时的安全管控规则集合，包括权限控制、操作审批、数据访问限制等，确保 Agent 在合规范围内执行任务。 |
| 审计日志 | 审计日志记录 Agent 的所有操作行为，包括任务执行、工具调用、数据访问等，用于安全审计、问题排查和合规追踪。 |
| 成本分析 | 成本分析提供 Agent 运行过程中的 Token 消耗统计与模型调用分析能力，帮助管理者掌握资源使用情况并进行成本优化。 |
| 高代码Agent | 高代码Agent 是基于 ADL（Agent Definition Language）编程定义的高级 Agent，支持复杂业务逻辑编排和自定义工作流，适用于需要精细控制的场景。 |
| 项目（Project） | 项目是业务维度的组织单元，用于按项目维度管理 Agent、分配资源和统计分析，实现多业务线的隔离与协作。 |
| 能力与插件 | 能力与插件是 V1.1.1 的统一管理概念，将技能（Skill）和 MCP 整合为统一的能力管理页面，提供一站式的能力注册、发现和调用体验。 |
| ADL Memory | ADL Memory 是 Agent 定义语言（ADL）中的持久化记忆机制，支持 Agent 跨会话保持上下文状态，实现长期记忆和个性化交互。 |
| 安全沙箱 | 安全沙箱是 Agent 运行时的隔离环境，提供文件防护和工具防护能力，确保 Agent 在受限环境中安全执行操作，防止越权访问。 |
| 运行态势图 | 运行态势图是面向 AI 操作的运行态势可视化大盘，聚合对话数、活跃 Agent、Token消耗、模型调用等核心指标，帮助运营人员掌握平台整体运行状况。 |
| 评估器 | 评估器是效果评估中用于对 Agent 运行结果进行打分的规则单元，支持系统内置评估器与自定义评估器，可按类别、评分类型配置评估规则。 |
| 数据集 | 数据集是用于训练、评测与数据回流的样本资产，可通过数据处理从 Trace 等来源清洗生成，为效果评估提供统一、干净的数据来源。 |
