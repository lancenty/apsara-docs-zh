# 1.产品详情

智能体计算实例ACI（Agent Compute Instance）是面向智能体（Agent）场景的安全沙箱算力服务。ACI采用轻量虚拟化技术，兼具虚拟机的隔离性和容器的启动速度，您无需管理底层服务器，只需提供打包好的容器镜像，即可快速创建、运行和释放弹性容器组。

ACI面向智能体等需要执行不可信代码的场景，提供安全、弹性的沙箱算力，在隔离性、启动速度和内存开销之间取得平衡。一个弹性容器组由一个或多个容器组成，拥有独立的IP地址和生命周期；您无需管理和配置底层服务器，即可在控制台快速部署容器化算力。

- **安全隔离**：基于轻量虚拟化技术提供虚拟机级的隔离能力，防止不可信代码影响其他租户与平台。默认情况下，ACI禁止容器组之间互相访问，即使是同一账号下的容器组也默认禁止；同账号的容器组与云虚拟机之间允许通信，便于容器组访问您的数据库等云资源。

- **实例预热**：支持通过预热池常备一批已就绪的实例，提前将网络、云盘等资源配置好，创建弹性容器组时直接命中池内实例，省去冷启动耗时。

- **云上集成**：弹性容器组接入专有网络VPC，占用指定虚拟交换机的一个弹性网卡，默认具备独立的内网IP地址，并可通过安全组控制出入流量；支持通过数据卷挂载云盘等存储，满足数据持久化需求。

- **弹性易用**：无需预先创建集群，也无需关注运行过程中的容量规划；在控制台即可完成弹性容器组和预热池的创建、查看、配置与释放，按需使用、随起随停。

# 2.产品价值

**安全隔离**

采用轻量虚拟化技术，为每个弹性容器组提供虚拟机级的隔离能力，运行大模型生成的、未经信任的代码时，容器组之间互不影响。默认情况下，ACI禁止容器组之间互相访问，即使是同一账号下的容器组也默认禁止，进一步收紧安全边界；同账号的容器组与云虚拟机之间允许通信，便于容器组访问您的数据库等云资源。

**极速启动**

兼具虚拟机的隔离性和容器的启动速度，弹性容器组无需漫长的系统启动过程，可在秒级完成创建并进入运行状态，为智能体等随起随停、高并发的短任务负载提供极速的弹性算力供给。您无需预先创建集群，也无需关注运行过程中的容量规划。

**实例预热**

支持通过预热池常备一批已就绪的实例，提前将网络、云盘等资源配置好并保持常备状态，创建弹性容器组时直接命中池内已就绪的实例，进一步省去冷启动耗时。预热池支持水位管理，您可以设定池内需要常备的实例数量（目标水位），并选择持续补水（水位低于目标即拉起新实例）或只减不增（不自动补建新实例）两种补水策略，实现性能与成本的灵活平衡。

**低成本**

内存开销显著低于传统虚拟机，支持更高密度的实例部署，提升算力资源利用率。弹性容器组按需创建、用完即释放，配合预热池的水位调节能力，避免资源闲置造成的浪费。

**易用性**

提供简单易用的统一管理控制界面，您可以直接创建和管理弹性容器组和预热池，无需复杂集群运维，满足快速部署、临时任务等轻量场景。

**高密**

采用轻量虚拟化技术，单台物理机即可承载高密度的弹性容器组部署，为智能体等场景下大规模并发任务提供充足的弹性算力供给，提升算力资源利用率。

<a id="section-3"></a>

# 3.应用场景

ACI为智能体（Agent）等需要执行不可信代码的场景提供安全、弹性的沙箱算力，兼具虚拟机的隔离性和容器的启动速度，全面适配随起随停的短任务负载。

**智能体（Agent）执行沙箱**

智能体在执行任务时，需要与真实、隔离的计算环境持续交互：浏览代码仓库、编写与修改文件、安装依赖、执行命令、运行测试、调用工具与服务。典型应用包括代码生成与执行（运行大模型生成的、未经信任的代码和脚本）、软件工程任务（在完整的代码仓库上完成修改、构建与测试）、工具调用与数据处理（运行复杂工具链、分析处理数据、访问数据库等云资源）等。在大规模批量任务中，执行环境往往在短时间内集中创建、集中释放。

智能体执行的是大模型生成的、未经信任的代码，且行为难以完全预期，可能尝试越权访问或破坏运行环境；共享宿主机内核的容器隔离性较弱，不适合运行此类负载。虚拟机的启动耗时和内存开销又难以支撑高并发的任务调度。ACI为智能体提供安全沙箱算力：以虚拟机级的隔离性保障不可信代码安全运行，以接近容器的启动速度支撑高并发任务调度；支持弹性容器组的秒级创建，并可借助预热池提前就绪大量实例，从容应对大规模并发需求；通过默认禁止容器组互访与安全组出入流量控制，将智能体行为的影响限制在单个容器组内。

**弹性短时任务**

对于代码执行、数据处理等按需触发的短时任务，ACI支持随用随建、用完即释放弹性容器组，避免资源闲置。结合预热池的快照预热能力，可将网络、云盘等资源提前配置就绪，任务请求到达时直接命中池内已就绪实例，快速响应业务波动，显著降低任务等待时间。

**长程任务**

智能体并非只有随起随停的短任务，复杂任务编排、持续交互等长程任务需要长时间运行。ACI支持容器组的休眠与唤醒：任务空闲时可将容器组休眠，保存运行状态并释放CPU、内存等资源，降低长程任务的运行成本；任务恢复时快速唤醒容器组，保留原有上下文，无需重建运行环境即可继续执行。

# 4.功能特性

本文介绍智能体计算实例ACI的功能特性。

**容器组管理**

弹性容器组是ACI中的核心资源对象，由一个或多个容器组成，拥有独立的IP地址和生命周期。一个容器组包含计算规格、容器与镜像、网络、存储等部分。

<table>
  <tr>
    <th width="106">功能&amp;特性</th>
    <th>说明</th>
  </tr>
  <tr>
    <td>弹性容器组</td>
    <td>Serverless化的容器运行服务。一个弹性容器组由一个或多个容器组成，拥有独立的IP地址和生命周期，用于运行智能体等随起随停的短任务。您无需管理底层服务器，只需提供打包好的容器镜像即可运行容器。</td>
  </tr>
  <tr>
    <td>计算规格</td>
    <td>支持两种资源配置方式：<br>• 基础模式：自行设置CPU和内存，并可指定CPU类型（intel、海光）。<br>• 指定规格：从实例规格列表中选择具体规格，列表展示实例规格、状态（可用/用完）、CPU类型、CPU核数、内存等信息。</td>
  </tr>
  <tr>
    <td>容器与镜像</td>
    <td>一个容器组由一个或多个容器组成，每个容器需指定容器镜像。镜像需要鉴权拉取时，可配置镜像仓库访问凭证（仓库地址、用户名和密码），并支持按需拉取或总是拉取。</td>
  </tr>
  <tr>
    <td>存储</td>
    <td>容器组具备临时存储空间，并支持通过数据卷挂载以下内容供容器使用：<br>• 配置项：用于向容器组注入配置数据。<br>• 临时目录：用于临时存放数据，便于容器之间共享数据，数据随容器组删除而清空。<br>• 云盘：实现数据持久化存储。</td>
  </tr>
  <tr>
    <td>预热池</td>
    <td>按固定资源需求常备一批已就绪的实例，创建弹性容器组时可直接命中池内实例以省去冷启动。支持水位（实时/目标）管理，可配置持续补水或只减不增的补水策略，并支持修改配置与删除。</td>
  </tr>
  <tr>
    <td>生命周期</td>
    <td>弹性容器组创建后依次经历调度中、等待中、运行中等状态，并在运行结束后进入已完成或失败等终态。支持失败后重启、总是重启、永不重启三种重启策略，用于定义容器退出后的重启行为。</td>
  </tr>
</table>
