# 1.什么是超级计算集群 SCC

裸金属算力（Bare Metal Computing Platform，简称BMCP）平台是一个前沿的技术解决方案，旨在为高性能计算需求的企业和开发人员提供强大、灵活且高效的计算资源。该平台通过构建基于服务器的裸金属集群，为用户提供了一种无虚拟化层的直接硬件访问方式，从而确保了最大程度的性能输出和优化的资源利用率。超级计算集群SCC集成了BMCP 的原有的超算类型的实例，独立成 SCC 的超级计算集群的控制台。

**特点和优势**

- 高性能：裸金属服务器提供不受虚拟化技术影响的原生硬件性能，使得计算密集型和存储密集型应用可以实现更高的执行效率。

- 专属资源使用：用户获得专属的物理服务器资源，这意味着不会有“邻居”干扰，保证了更稳定的计算和存储性能。

- 灵活配置：根据不同的应用需求，用户可以选择最适合的硬件配置，包括处理器、内存、存储和网络资源等，以实现最优的性能与成本平衡。

- 即时可用性：与传统的物理服务器部署相比，裸金属算力平台能够提供更快的部署速度，让用户能够迅速启动项目，缩短项目上线时间。

- 安全与隔离：由于用户对硬件资源具有完全的控制权，这提供了更高级别的安全性和隔离性，尤其适合对安全性和合规性要求较高的业务场景。

> **说明**
>
> 该裸金属算力平台是面向未来的企业级解决方案，适合需要处理大规模计算任务的科研机构、智能计算任务、大型互联网公司和金融行业等，为他们提供了一个既强大又灵活的计算环境。

**集群与节点**

**集群**

**集群**是超级计算集群SCC平台面向用户提供的一个很重要的管理对象，通过**集群管理**，用户可基于不同实例规格，构建业务所需的超算集群，配套提供集群的生命周期管理能力以及存储挂载、应用部署等增值能力。

- 支持一键创建高性能计算集群。

- 支持多种实例规格，包括**高性能计算高网**和**高性能计算纳管**。用户可根据自身业务特点选择合适的规格实例，以构建算力集群。

- 支持集群的创建、删除、扩容、缩容等生命周期管理功能。

- 集群状态查看，包括集群的ID、名称、标签、状态、数量、资源情况及网络配置等基础信息。

**节点**

节点是超级计算集群SCC算力平台面向用户提供的最小粒度的管理单元，通过**节点管理**，用户可查看当前集群各个节点的属性、运行状态等，支持节点操作，用于管理和使用节点资源。

- 支持远程登录、节点的启用与停用、重启以及节点监控等管理功能。

- 支持节点状态的查看，包括节点的ID、名称、状态、标签、所属集群及网络配置等基础信息。

- 针对**高性能计算纳管**集群，支持基于NFS和iSCSI协议的远程文件系统挂载。

**机型与镜像**

**机型与镜像**功能属于BMCP裸金属算力平台管理的基础资源，包括当前平台可支持的实例规格对应的机型信息和裸机镜像信息等。

- **节点机型**：

  - 支持设置可管理裸金属的机型范围，添加机型后，方可在创建裸金属集群及实例时选到已经添加的机型。

  - 支持对机型进行增加、删除、修改及查询等操作。

- **裸机镜像**：

  - 裸机镜像用于维护裸机装机或创建集群时使用的镜像元数据，目前提供了多种选择，包括**自定义镜像**和**公共镜像**。

  - 提供了**自定义镜像**的查询、状态管理、删除、导出等功能。

  - 提供了**公共镜像**的查询、状态管理、导出等功能，您可以根据需求自定义上传所需的镜像。

**网络与安全**

**网络与安全**提供用于创建或维护算力集群时所需的网络信息，包括：

- **专有网络VPC**：用于超级计算集群SCC平台创建集群时所依赖的VPC网络管理服务，支持跳转至专有网络VPC的控制台。

- **EVPC管理**：

  - EVPC（Enterprise Virtual Private Cloud）用于管理智算节点的RDMA网络。通过EVPC，可实现智算节点RDMA网段和子网的管理，以及不同智算集群间RDMA网络的隔离。

  - 支持创建、编辑、删除以及查询和查看EVPC功能。

  - 只有高性能计算高网实例支持配置EVPC。

- **安全组**：安全组是一种虚拟防火墙，用于控安全组内实例的入流量和出流量，实现对裸机实例流量细粒度的控制，阻止非法访问，从而提高实例的安全性。

- **密钥对**：提供一种安全便捷的登录认证方式，由公钥和私钥组成，可用于用户权限的有效管理。

- **裸机网络**：裸机网络提供了解堆叠HSW和CHSW场景下，VSwitch与专线网关之间的绑定关系管理功能。

**标签管理**

超级计算集群SCC平台接入了Apsara Uni-manager运营控制台的标签管理，标签用于从不同维度对资源分类管理。

- 面向超算资源的标签管理功能，支持按需进行自定义标签配置。

- 支持跳转至ASCM**资源运营 > 标签管理 > 标签**进行管理。

**计量数据**

超级计算集群SCC（归属裸金属算力平台BMCP）接入了Apsara Uni-manager运营控制台的计量管理，提供裸金属算力平台的资源数据统计功能。

- 支持超算节点级别的计量能力，能够提供GPU卡、CPU、内存等资源层面的计量。

- 支持跳转至ASCM**资源运营 > 计量管理 > 计量明细**进行管理。

# 2.登录超级计算集群 SCC

本节为您介绍如何登录到Apsara Uni-manage运营控制台，并进入超级计算集群 SCC。

**前提条件**

- 您需要登录Apsara Uni-manage运营控制台后进入超级计算集群 SCC，请提前确认您已从部署人员处获取Apsara Uni-manage运营控制台的服务域名地址。

- 推荐使用Chrome浏览器。

**操作步骤**

1. 在浏览器地址栏中，输入Apsara Uni-manage运营控制台的访问地址，按回车键。

2. 输入正确的用户名及密码。

   *请向运营管理员获取登录控制台的用户名和密码。*

   > **说明**
   >
   > 首次登录ASCM控制台时，需要修改登录用户名的密码，请按照提示完成密码修改。为提高安全性，密码长度必须为 8~20 位，且至少包含以下两种类型：
   >
   > - 英文大写或小写字母（A~Z、a~z）
   >
   > - 阿拉伯数字（0~9）
   >
   > - 特殊符号（感叹号（！）、at（@）、井号（#）、美元符号（$）、百分号（%）等）
   >
   > *admin管理员账号具有所有权限，操作不受限，在运营管理中请慎重操作！*

3. 单击**登录**，进入Apsara Uni-manage运营控制台页面。

4. 在页面顶部的菜单栏中，选择**产品 > 计算 > 超级计算集群 SCC**。

### 3.1.2. 查看集群详情

本节介绍如何查询集群以及查看集群详细信息。

**前提条件**

已创建超级计算集群 SCC。

**操作步骤**

1. 登录超级计算集群 SCC。

2. 在左侧导航栏中，单击**集群与节点 > 集群管理**。

## 6.5. 裸机网络

裸机网络提供了解堆叠HSW和CHSW场景下，VSwitch与专线网关之间的绑定关系管理功能。

**绑定专线网关**

**注意事项**

- 同一个 VSwitch 不能同时用于跨堆叠和去堆叠的交换机组网环境。

  - 如果堆叠的 HSW 或者 CHSW 上的机器使用了这个 VSwitch，则该 VSwitch 就不能再绑定专线网关。

  - 如果一个 VSwitch 已经绑定了专线网关，则连接堆叠 HSW 或 CHSW 的机器就不能再使用这个VSwitch。

- 同一个 VSwitch 只能绑定一个专线网关。

- 同一个 VSwitch 不能同时用于 HSW 和 CHSW 交换机组网环境。

  - 如果 VSwitch 绑定了 HSW 类型的专线网关，则 CHSW 上的机器不能再使用该 VSwitch。

  - 如果 VSwitch 绑定了 CHSW 类型的专线网关，则 HSW 上的机器不能再使用该 VSwitch。

**操作步骤**

1. 登录超级计算集群 SCC。

2. 在左侧导航栏，单击**网络与安全 > 裸机网络**。

   跳转到裸金属算力平台 BMCP控制台的**裸机网络**页面。

3. 单击**绑定专线网关**。

4. 在**基本信息**区域，选择**组织**、**资源集**和**地域**。

5. 在**绑定专线网关**区域选择**VPC**、**VSwitch**和**专线网关设备**。

6. 单击**提交**。

   提交后，在裸机网络界面可以看到绑定的专线网关信息，状态为**绑定中**。绑定成功后，状态变为**生效**。

**解绑专线网关**

1. 查找专线网关。

   支持通过**裸机网络ID**、**交换机ID**、**专线网关设备1**和**专线网关设备2**进行筛选。

2. 在目标专线网关**操作**列，单击**解绑**。

3. 单击**确定**。

   解绑成功后，在裸机网络页面查询不到该条信息。

   单击标签键右侧的 <img src="zh-scc-user-guide-v3.18.6-20261023.assets/e18d59a05842dfa9819ac08d1e42320b.webp" width="11" alt=""> ，设置**筛选条件**，包括**资源所在的组织**、**资源所在的资源集**、**资源所在的地域**和**关**

   **键字**。

4. 单击目标标签键，在右侧区域查看标签键对应的标签值和绑定的云产品。

   <ol type="i">

   <li>

   单击目标标签值左侧的 <img src="zh-scc-user-guide-v3.18.6-20261023.assets/fb33416657f639f132c8b9afda9303b0.webp" width="15" alt=""> ，查看标签具体绑定的云产品。

   </li>

   <li>

   </li>

   <li>

   <ol type="i">

   <li>

# 8.计量数据

超级计算集群（归属裸金属算力平台BMCP）接入Apsara Uni-manager运营控制台计量管理，提供裸金属算力平台 BMCP产品的资源实例数量，按照时间维度、组织维度、资源集维度和地域维度进行统计展示和导出。

**操作步骤**

1. 登录超级计算集群 SCC。

2. 在左侧导航栏中单击**计量数据**，跳转到**计量明细**页面。

3. 在跳转的**计量明细**页面中，在**资源**下拉列表中选择**裸金属-超算算力集群**，单击**搜索**，查看集群资源的明细计量数据。

   您可以根据实际需要继续设置**组织**、**资源集**、**地域**、**时间**、**实例ID**进行筛选；单击页面右上角 <img src="zh-scc-user-guide-v3.18.6-20261023.assets/579eb0dfa9d9525b8483bb5bec51b0d7.webp" width="19" alt=""> 图

   标，可将当前查询接口以xlsx文件格式导出至本地。

   > **说明**
   >
   > 在控制台查看和导出.xlsx文件时，最多只能查看或导出1000条计量数据。如需查询更多计量数据，需要调用计量查询接口进行获取。
